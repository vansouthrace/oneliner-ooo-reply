## About

An entry for the [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty "Funniest One-Line Out-of-Office Reply": the funniest one-line out-of-office email auto-reply. Instead of the usual beach or inbox clichés, this one hands the inbox to a houseplant with strong boundaries.

## Entry

> I am away, and my inbox is being looked after by a ficus plant. It has read everything, judged nothing, and will reply to no one.

## How to run

Requires Node 22.18+:

```sh
node main.ts
```

It writes the entry to `/output/entry.txt`.

## Verification

- Entry length: 129 characters (limit: 1-160 characters).
- Single line, plain text, no trailing newline inside the entry.
- It still reads like a real away message — away, inbox covered, no reply expected — while the ficus quietly does a better job than most colleagues.
